# 2old4this Stages Vol.3 简体中文汉化

这是一个不修改原模组文件的独立伴生汉化模组，翻译范围包括：

- `journals` 日志合集包的完整正文与页面名称；
- `maps` 场景合集包的场景名称；
- 舞台控制台、指示物调整器、关键词管理器；
- 模组设置、素材文件夹检查器、操作提示与错误消息；
- 场景工具栏按钮和模组管理页中的说明。

路径、文件名、筛选关键字、图片地址、UUID、宏命令和功能事件均保持原样，避免影响原模组运行。

## 依赖

- Babele
- 2old4this Stages Vol.3（3.0.3 或更高版本）

## 安装

将整个 `2old4this-stages-vol3-zh-cn` 文件夹复制到 Foundry VTT 的 `Data/modules/`，并在世界中同时启用原模组、Babele 与本汉化模组。Foundry 的界面语言需设为“简体中文”。

### 推荐：通过网址安装

在 Foundry VTT 的设置首页选择“附加模组 → 安装模组”，输入：

```text
https://github.com/hachimenHato/2old4this-stages-vol3-zh-cn/releases/latest/download/module.json
```

当前版本：**1.0.0**。需要 **Foundry VTT 13、Babele，以及 2old4this Stages Vol.3 3.0.3 或更高版本**。安装链接始终指向最新正式版，可用于后续更新。

如果手动安装，从 Releases 下载 `2old4this-stages-vol3-zh-cn.zip`，将内容放入同名模组目录，使 `module.json` 位于第一层，然后重新载入世界。

## 使用与兼容

本项目不包含像素素材、场景资源或原模组程序。请先通过 [2old4this 的发布渠道](https://www.patreon.com/2old4this) 获取原模组。

合集汉化在读取时应用；世界内已导入的旧日志和场景不会被自动批量改写。原模组新增页面、修改模板或变更字段后，可能需要更新汉化。
